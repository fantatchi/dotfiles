# 画像生成プロンプト組み立て

`$ARGUMENTS`（欲しい画像の日本語での説明）から、**そのままコピーして画像生成モデルに貼れる英語プロンプトを 1 本**組み立てて返す。

## 狙い

素の依頼をそのまま画像生成モデルに投げると、ツルツルした質感・過剰な彩度・情報過多の背景という「AI っぽさ」が出る。本スキルは、**不完全さを名指しで要求し、画材の物理的な癖を借り、色数と余白を数字で縛り、禁止事項を先に潰す**という 4 つの操作を必ず通すことで、これを構造的に避ける。

したがって出力は**プロンプト 1 本で確定**させる。候補を並べて選ばせない（迷いはユーザー側の仕事ではない）。画風は用途から自動で決め、理由を 1〜2 行添える。

## 手順

### 1. 依頼を 4 つの軸に分解する

`$ARGUMENTS` から次を読み取る。書かれていなければ**聞かずに用途から推定して決め打つ**（後段でユーザーが言い直せばよい）。

| 軸 | 例 |
|---|---|
| 用途 | ブログのアイキャッチ / 資料の説明図 / SNS / 教材 / アイコン |
| 被写体 | 何が写るか。人物の有無・人数 |
| 雰囲気 | 明るい / 落ち着いた / レトロ / 素朴 |
| 比率 | 記述があれば拾う。なければ用途から（アイキャッチ 16:9、アイコン 1:1、資料 4:3） |

### 2. 画風を 1 つ選ぶ

`references/styles.md` から 1 つ選ぶ。用途からの入口:

| 用途 | まず見る分類 | 既定の選択 |
|---|---|---|
| ブログ・記事のアイキャッチ | 2 フラット・エディトリアル系 / 1 手描き系 | `low-ai-flat` |
| 技術記事・SaaS 紹介 | 2 フラット・エディトリアル系 | `startup-web` |
| 抽象概念の可視化 | 2 フラット・エディトリアル系 | `magazine-spot` |
| 資料・スライドの説明図 | 6 実務・教材系 | `educational` |
| 手順書・研修 | 6 実務・教材系 | `textbook` |
| 一覧に並ぶアイコン | 6 実務・教材系 | `icon-pictogram` |
| 読み物・エッセイ | 1 手描き・アナログ画材系 | `watercolor-ink` |
| 子ども向け・やさしい説明 | 1 手描き系 | `picture-book` |
| 社内資料・肩の力を抜いた説明 | 3 ポップ・キャラクター系 | `loose-cute` |
| レトロ・ZINE・イベント | 4 印刷・版画系 | `risograph` |
| 和風・季節の行事 | 4 印刷・版画系 | `woodblock` |
| ストーリー仕立て | 5 漫画・ゲーム系 | `manga-loose` |

依頼に画材や質感の語（水彩・鉛筆・版画・切り絵など）があれば、上表より**その指定を優先**する。

### 3. 5 ブロックで組み立てる

`references/avoid.md` から、被写体に該当する断片だけを選んで差し込む。**全部入れない**（合計 6 行程度に収める。盛りすぎ自体が AI っぽさを生む）。

```
SUBJECT: <被写体と場面を英語で 1〜2 文。動作・場所・時間帯まで具体に>
VISUAL STYLE: <styles.md の断片 + 色数と彩度の指定>
HUMAN-MADE CHARACTER: <不完全さの名指し。人物がいれば姿勢・表情の指定も>
COMPOSITION: <主題 1 つ、補助オブジェクト数、余白、背景、アスペクト比>
AVOID: <該当する禁止事項。文字を入れないなら no text も>
```

必ず守る 3 点:

- **`VISUAL STYLE` に色数を数字で書く**（`limited three-to-five-color palette` など）
- **`HUMAN-MADE CHARACTER` は「どこがどう狂うか」を書く**。`natural` `organic` のような形容詞だけでは効かない
- **`AVOID` を空にしない**。最低でもツルツル質感と過剰彩度は潰す

### 4. 出力する

応答は次の 3 つだけ。前置き・手順の説明は書かない。

1. 英語プロンプトのコードブロック 1 つ
2. 「`<画風名>` を選んだ理由」1〜2 行（日本語）
3. 「別の方向なら: `<画風 A>` / `<画風 B>`」の 1 行（名前だけ。プロンプトは作らない）

## 言い直しへの対応

「もっとゆるく」「別画風で」「人物を減らして」と言われたら、**差分だけ直して全文を再出力**する。変更点を説明する行は 1 行に留める。

## やらないこと

- 画像そのものを生成しない（プロンプトを返すまでが担当）
- 候補を 3 つ並べて選ばせない（1 本で確定させる）
- 実在の作家名・スタジオ名・作品名を画風指定に使わない。画風は画材と処理の言葉で記述する
